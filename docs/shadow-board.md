# Shadow Board: the seven lenses

Each lens independently challenges a theory for one failure mode, drawing on structured intelligence-analysis tradecraft. A lens returns a verdict, a severity, and a rationale.

1. Source reliability: provenance and trustworthiness of the underlying evidence.
2. Confirmation bias: is the theory only selecting evidence that confirms it.
3. Denial and deception (D&D): could the signal be deliberately planted or manipulated.
4. Analysis of competing hypotheses (ACH): are stronger alternative explanations being ignored.
5. Incentive analysis (cui bono): who benefits if this theory is believed.
6. Logical coherence: internal consistency and logical-fallacy check.
7. Base rate: is the theory ignoring prior probabilities and base rates.
